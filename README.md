# Sentiment Analysis Pipeline

Ce projet implémente un pipeline d'analyse des sentiments en Python. Il prend en entrée un fichier CSV contenant des textes et leurs scores de sentiment, puis applique différentes étapes de traitement et d'inférence.

## Structure du Projet


Sentiment-Analysis-Pipeline/
│── src/
│   ├── __init__.py
│   ├── data_extraction.py  # Chargement des données
│   ├── data_processing.py  # Prétraitement des données
│   ├── inference.py        # Prédiction des sentiments
│   ├── model.py            # Modèle d'analyse des sentiments
│── tests/                  # Tests unitaires
│── dataset.csv             # Fichier de données
│── requirements.txt        # Dépendances du projet
│── README.md               # Documentation du projet
│── test.txt                # Fichier de test
│── .gitignore              # Fichiers à ignorer par Git
